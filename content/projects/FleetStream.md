A real-time, event-driven telemetry pipeline using Go and Kafka, handling 10K+ concurrent events with sub-second end-to-end latency. Features fault-tolerant microservices with Kafka consumer groups on AWS and an anomaly-detection microservice with WebSocket-based alerts, reducing message lag by 40% in high-throughput scenarios.
