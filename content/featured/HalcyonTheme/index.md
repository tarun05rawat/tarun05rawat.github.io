**SnippetShare** is a **TypeScript-based VS Code extension** for secure team code-snippet collaboration. Built with a **Flask backend, Firebase Auth, and Firestore database**, it supports real-time sync for up to 25 developers per workspace, **optimizing snippet retrieval time**. Its integrated **VS Code UI** leverages the **Webview API, custom CSS/JS, and keyboard shortcuts** to boost integration efficiency, showcasing full-stack expertise in **TypeScript, API design, and VS Code extension architecture**.
