Developed a **VS Code extension** empowering **50+ developers** to share, organize, and search code snippets across private and global workspaces, improving collaboration efficiency by **40%**. Engineered a secure **Flask API layer** integrated with **Firebase Firestore** and **Firebase Auth**, enabling low-latency data synchronization and authenticated snippet access. Implemented a responsive UI with **syntax highlighting, workspace navigation, and GitHub OAuth onboarding**, providing a seamless developer experience within the VS Code ecosystem.
