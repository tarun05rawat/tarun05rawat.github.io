Designed a **real-time, event-driven telemetry pipeline** using **Go and Kafka**, handling **10K+ concurrent events** with sub-second end-to-end latency. Implemented **fault-tolerant microservices** and message processing using **Kafka consumer groups**, deploying containerized services on **AWS** to ensure reliable ingestion under load. Built an **anomaly-detection microservice** with concurrent event handling and **WebSocket-based alerts**, reducing message lag by **40%** in high-throughput scenarios.
